# Frequency research

The ranking of the stack is only as good as this count, so do it per sub-question and keep the raw tally.

## 1. Tally sheet (working notes)

One row per sub-question, across all papers:

| Paper | Q | Pts | Topic / chapter | Task type | Notes |
|---|---|---|---|---|---|
| Exam 2023 | 5a | 4 | Irreducible polynomials | Name the gcds of the irreducibility test | Explain only, no computing |
| Exam 2022 | 4a | 2 | Irreducible polynomials | Name the gcds of the irreducibility test | "indexed form is fine" |
| … | | | | | |

**Task type** is the skill the grader checks, not the chapter. Two questions belong to the same task when one recipe solves both. Split a chapter into several tasks when it's examined in clearly different ways (e.g. "compute an order" vs "count primitive elements").

## 2. Aggregate

| # | Task type | Papers (x/N) | Typical pts | Share of all pts | Ease | Notes |
|---|---|---|---|---|---|---|
| 1 | Liars/witnesses table | 6/6 | 8–13 | 16% | easy | powers are given; reading carefully |
| … | | | | | | |

- **Papers (x/N):** on how many of the N papers it appeared, at least once.
- **Share of all points:** the sum of its points ÷ the sum of all papers' points. Normalize first if papers have different totals: convert each paper to 100.
- **Typical pts:** the range when it appears.

## 3. Write-up for the student (`recurring-exam-questions.md`)

1. One paragraph: which papers were used, and any caveats (a changed syllabus, a missing year, solutions that weren't official).
2. The aggregate table, ranked.
3. Per task: one or two lines on what the question usually looks like, with the typical phrasing ("Decide with the lecture's algorithm whether a is primitive, explaining every step").
4. A short "always on the paper" list: the tasks at N/N. Students use it as a final checklist.

## Edge cases

- **Resits and alternative versions** count as papers, but mark them. If the regular exams and resits differ systematically, mention it.
- **Changed syllabus:** drop papers, or individual questions, on material no longer taught. Check the current course guide or "what to study" list if one exists, and say what you dropped.
- **Merged or renamed topics:** tally by task type, not by the paper's section headings.
- **Optional / choice questions** ("answer 3 of 4"): count them, but weight by the chance the student would pick them, or note it.
- **Bonus or "hard" questions** that appear once: keep them as low-ranked cards. A student who finishes the stack will want them.
- **Very few papers (1–2):** say the ranking is weak and lean more on the course's stated learning goals.
